Twój nowy workflow

Przekształcamy chaos w uporządkowany proces. Oszczędzasz czas na każdej interakcji z modelem.

1

Błyskawiczny Kontekst

Wpisujesz w terminalu filec .\CONTEXT.md. Struktura i założenia projektu lądują w schowku. Wklejasz to na start rozmowy — AI od razu "czuje" Twój kod.

2

Precyzyjne Polecenia

Zaczynasz wiadomość od magicznego słowa: TERMINAL: dodaj bazę danych. Model odpowiada tylko i wyłącznie gotowym blokiem komend do skopiowania. Zero tłumaczenia teorii.

3

Łapanie Błędów w Lot

Aplikacja wybuchła? Konsola zalała się czerwonym błędem, który zniknął na górze ekranu? Wpisujesz loglast. Ostatnie akcje trafiają do schowka. Wklejasz do AI i naprawiasz.

powershell.exe - Void Workflow
user@void:~/app$ filec .\CONTEXT.md

Gotowe do wklejenia w ChatGPT

Twój Arsenał

Te dwa elementy diametralnie zmieniają jakość odpowiedzi i Twoją szybkość w konsoli.

Tagi dla ChatGPT

Wpisuj je na początku wiadomości (wynikają z wgranego promptu):

  • TERMINAL: Czysty kod powłoki. Zawsze podaje komendę weryfikującą sukces.
  • PLIK: Cały kod pliku od góry do dołu. Zaznaczasz Ctrl+A i wklejasz. Zero domysłów.
  • HANDOFF: Spisuje wiedzę na koniec pracy, aby uaktualnić plik pamięci projektu.

Skróty PowerShell

Funkcje dodawane prosto do Twojego Windows Terminala:

  • runc "npm run dev"

    Odpala komendę, a jej wynik ląduje w schowku. Idealne do przekazania logów na bieżąco.

  • tree2

    Kopiuje mapę plików (do 2 lub 3 poziomów w głąb), omijając ciężkie foldery jak node_modules.

  • gs = git status
    gl = lista ostatnich commitów

Prosta Instalacja

Skonfiguruj środowisko w 5 minut. Wystarczy skopiować dwa pliki i raz użyć terminala.

Pobierz pliki instalacyjne z GitHub
1

Zaktualizuj mózg ChatGPT

Ten krok sprawi, że ChatGPT zacznie reagować na tagi typu TERMINAL:.

  1. W ChatGPT (WWW) kliknij ikonę profilu → Settings → Personalization.
  2. Wybierz Custom instructions.
  3. Z repozytorium GitHub skopiuj treść pliku chatgpt-prompt.md (sekcja ŚRODOWISKO).
  4. Wklej w dolne pole: "How would you like ChatGPT to respond?" i zapisz.
2

Wgraj profil PowerShell

Ten krok dodaje komendy (np. `loglast`, `filec`) i nagrywanie błędów do Twojego komputera.

A. Wklej to w Windows Terminal, by otworzyć plik ustawień:

# Zrób to w zwykłym Windows Terminal (PowerShell)
if (-not (Test-Path $PROFILE)) { New-Item -Path $PROFILE -ItemType File -Force }
notepad $PROFILE

B. Wklej kod ze schowka:

Otworzy się Notatnik. Skopiuj całą zawartość pliku powershell-profile.ps1 (z GitHuba), wklej, zapisz (Ctrl+S) i zamknij.

C. Aktywuj:

. $PROFILE

Błąd z zablokowanymi skryptami? Wpisz raz: Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned i potwierdź.

3

Stwórz CONTEXT.md (Baza wiedzy)

Dla każdego nowego projektu, twórz w jego głównym folderze plik CONTEXT.md.

Skopiuj szablon z context-template.md i uzupełniaj go w miarę rozwoju aplikacji. Jeśli wskakujesz w stary projekt, poproś model:
HANDOFF: przygotuj CONTEXT.md na podstawie tej rozmowy.
