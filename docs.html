Baza Wiedzy (Cheatsheet)

Wszystkie magiczne słowa, komendy i skróty, które ułatwiają vibe-coding w jednym miejscu.

Tagi dla ChatGPT

Wpisuj na samym początku wiadomości na czacie, by zmusić AI do konkretnego zachowania.

TERMINAL:

Każe wygenerować sam blok komend do skopiowania do konsoli. AI nie będzie niczego tłumaczyć, poda tylko kod i sposób jak sprawdzić czy się udało.

PLIK:

Otrzymujesz CAŁY kod pliku od góry do dołu. Idealne, gdy AI znowu pisze "wstaw tę linijkę gdzieś na górze".

HANDOFF:

Streszcza dzisiejszą pracę nad projektem, byś mógł zaktualizować swój plik CONTEXT.md.

WYJAŚNIJ:

Odwrotność TERMINAL:. Jeśli czegoś nie rozumiesz, AI ma obowiązek wytłumaczyć Ci to jak człowiekowi, używając metafor, BEZ podawania komend.

Pamięć projektu

Plik CONTEXT.md w katalogu projektu. Pełny przewodnik krok po kroku →

init-ctx

Tworzy szablon pamięci projektu (warianty: init-ctx nextjs, init-ctx vps)

ctx

Otwiera CONTEXT.md w VS Code, a gdy go nie ma — w Notatniku

ctxadd "Zmieniłem API"

Dopisuje datowaną notatkę na koniec pliku, bez otwierania edytora

ctx-done "koszyk"

Odhacza zadanie w roadmapie ([ ] → [x]) i zapisuje datę ukończenia

ctx-repo

Zakłada prywatne repo na GitHubie i wpisuje jego adres do CONTEXT.md

ctx-map

Mapa architektury: drzewo, zależności i importy lokalne jako prompt dla AI

Prompty dla AI

Każda z tych komend kopiuje gotowy prompt do schowka i (opcjonalnie) otwiera czat w przeglądarce.

onboard

Mega-prompt startowy: struktura projektu, package.json, README i CONTEXT.md

vibe-review

Bierze git diff i prosi o brutalnie szczere code review

explain .\src\app.js

Prosi o wyjaśnienie pliku linijka po linijce, prostym językiem

doc-gen

Prompt na kompletne README.md: opis, instalacja, struktura, FAQ

mock-data "użytkownicy" 50

Prompt na realistyczne dane testowe w czystym JSON

wtf

Łapie ostatni błąd z konsoli i prosi o wyjaśnienie plus komendę naprawczą

review

Starszy, prostszy wariant code review (sam diff, bez kontekstu projektu)

Git i zapisywanie

gsave "wiadomość"

Add, commit i push naraz. Fajerwerki, gdy commit domyka zadanie z roadmapy

gundo

Cofa ostatni commit, zostawiając zmiany w plikach (alias: undo, whoops)

gs

Skrócony git status z informacją o gałęzi

gl

Ostatnie 15 commitów w jednej linii każdy

safedeploy

Build, a gdy się wywali — treść błędu ląduje w schowku zamiast deployu

snapshot

Backup projektu do ZIP z pominięciem node_modules, .git i dist

Przenoszenie danych

filec .\plik.txt

Kopiuje zawartość pliku razem z nagłówkiem ze ścieżką

tree2

Kopiuje drzewo plików bez śmieci (domyślnie 2 poziomy, tree2 3 głębiej)

runc "npm run dev"

Uruchamia komendę, pokazuje wynik i od razu kopiuje go do schowka

loglast 50

Kopiuje ostatnie 50 linii z logu sesji — także te, które zniknęły z ekranu

Ratunek i porządki

npmnuke

Kasuje node_modules i package-lock, czyści cache, instaluje od nowa

clean-space

Usuwa node_modules, dist, .next, build i coverage — odzyskuje gigabajty

stats

Liczy pliki i linie kodu w projekcie

vibe-check

Pasywno-agresywny linter: znajduje najgrubszy plik i komentuje

rage-quit

(╯°□°）╯︵ ┻━┻ Awaryjny commit „WIP - ratunku" i zamknięcie terminala

Projekty i zadania

vp add [nazwa]

Zapisuje bieżący folder na liście projektów (domyślna nazwa = nazwa folderu)

vp go [nazwa]

Teleportuje do projektu i przypina ostatnią notatkę z CONTEXT.md do promptu

radar

Tabela wszystkich projektów: wykryty stack i status Gita

todo add "fix"

Dodaje zadanie. todo list, todo done 0, todo rm 0. Aktywne widać w HUD

scratch "myśl"

Przypina żółtą karteczkę do znaku zachęty (zdejmiesz przez scratch clear)

zapamietaj nazwa "komenda"

Zapisuje długą komendę pod krótką nazwą

przypomnij nazwa

Wykonuje zapamiętaną wcześniej komendę

Terminal i diagnostyka

void

Otwiera pełną pomoc w terminalu (alias: pomoc)

void doctor

Sprawdza git, gh, node, code, ExecutionPolicy i logowanie do GitHuba

cheat vps

Ściągawka trudnych komend (warianty: vps, git, npm)

focus

Tryb Zen — wyłącza ostrzeżenia offline i skaner zombie

brb

Blokuje ekran terminala napisem „Zaraz wracam"

qr-link 3000

Kod QR z lokalnym adresem IP do testów na telefonie

mock-server 8080

Prosty serwer statyczny HTTP w bieżącym folderze
